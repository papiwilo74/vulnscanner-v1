# Política de Seguridad

## Versiones Soportadas

Actualmente se proporciona soporte de seguridad y parches para las siguientes versiones:

| Versión | Soportada          |
| ------- | ------------------ |
| 2.0.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reportar una Vulnerabilidad

La seguridad de VulnScanner y de sus usuarios es una prioridad. Si descubres una vulnerabilidad de seguridad en esta herramienta, por favor repórtala de manera responsable:

1. **No abras un Issue público** describiendo la vulnerabilidad técnica.
2. Envía un correo directamente a: **villadaurechejuandavid20@gmail.com** con el asunto `[SECURITY] VulnScanner - Reporte de Vulnerabilidad`.
3. Proporciona los pasos detallados para reproducir el fallo, prueba de concepto (PoC) y versiones afectadas.

### Plazo de Respuesta

- **Confirmación inicial**: En menos de 48 horas.
- **Evaluación y triage**: Dentro de 5 días hábiles.
- **Lanzamiento de parche**: Se coordinará un parche y una divulgación responsable en GitHub Security Advisories.

## Alcance y Buenas Prácticas

VulnScanner es un escáner DAST defensivo diseñado exclusivamente para pruebas de seguridad autorizadas en sistemas propios o con consentimiento expreso por escrito. El uso de esta herramienta contra objetivos no autorizados está estrictamente prohibido.
